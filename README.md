# Cooking AI Assistant

A Flask + Google Gemini chatbot focused only on cooking and food-related questions.

Setup:
1. python -m venv venv
2. venv\Scripts\activate
3. pip install -r requirements.txt
4. Put your Gemini API key in .env
5. python app.py
6. Open http://127.0.0.1:5000

The chatbot answers cooking and food-preparation questions only.
